## 📌 About the Project

Smart Calculator is a simple command-line calculator built using Python. It takes two numbers from the user, asks them to choose a mathematical operation, and displays the result.

The project also handles invalid inputs and prevents division by zero.

## ✨ Features

- ➕ Addition of two numbers
- ➖ Subtraction of two numbers
- ✖️ Multiplication of two numbers
- ➗ Division of two numbers
- 🔄 Input validation for invalid numeric values
- ⚠️ Error handling for invalid operations
- 🛡️ Protection against division by zero

## 🛠️ Technologies Used

- **Language:** Python
- **Concepts:** Functions, user input, `while` loops, conditional statements, `try` and `except`, and basic debugging

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python day_01_calci.py
```
